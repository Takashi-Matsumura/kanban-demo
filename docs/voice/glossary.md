# 用語集・誤認識対応集

音声認識で頻発する誤変換と、現場で使われる略語・口語表現を整理する。
LLM はここに記載された対応関係を踏まえ、表記揺れを工程名や製品名に正規化する。

## 工程名の誤変換パターン

| 誤認識されやすい表現 | 正しい工程名 | 補足 |
|---|---|---|
| 整形、整型、正型、聖型、製形 | 成形 | 同音「せいけい」での誤変換 |
| 一時発行、一字発行、一次発光 | 一次発酵 | 「いちじはっこう」の同音変換 |
| 二次発光、二字発酵 | 二次発酵 | |
| 招請、上製、傷性、笑声 | 焼成 | 「しょうせい」の同音変換 |
| 放送、奉仕、報奨 | 包装 | 「ほうそう」の同音変換 |
| 県警、健品 | 検品 | |
| 出火、宿下、出貨 | 出荷 | |
| 礼客、霊客 | 冷却 | |
| 市子、仕事込み | 仕込 | |
| ベンチタイマー | ベンチタイム | |

## 担当者の呼び方

- 通常は「担当: 田中」のように姓のみで登録されているが、音声では「田中さん」「たなかさん」のように敬称付きで呼ばれることが多い
- 同音異字（佐藤＝砂糖、左藤、佐東）に注意

## 製品名の通称

| 通称・口語 | 正式名 |
|---|---|
| 食パン、角食、サンドイッチ用、角型 | 角食パン |
| バゲット、フランス | フランスパン |
| あんぱん | アンパン |

## バッチを特定するための手がかり

ユーザーは以下のような言い方でバッチを特定する:

- **製品名**: 「フランスパン」「角食パン」
- **ロットコード末尾**: 「フランス 01」「食パン 02」（ロットコードの末尾連番）
- **担当者**: 「田中さんの」「佐藤さんが担当している」
- **現在工程**: 「ホイロにいる」「焼成中の」「一次発酵中の」
- **シフト**: 「朝便の」「昼便の」「夕便の」

複数の手がかりが含まれる場合、それぞれを `product_hint` / `lot_hint` / `assignee_hint` /
`from_stage_hint` に分けて記載すること。

## 操作の言い回し

| 発話パターン | 意図 |
|---|---|
| 「成形へ」「成形に」「成形まで進めて」「成形に移して」 | to_stage に該当工程 |
| 「次へ」「次の工程に」「進める」「進めて」「先へ」 | direction: next |
| 「前へ」「戻す」「戻して」「前の工程に」「差し戻し」 | direction: prev |
| 「終わった」「上がった」「完了」 | direction: next（その工程が終わって次へ進む意味） |
| 「焼きに入れる」「オーブンに入れる」 | to_stage: 焼成 |
| 「ホイロに入れる」「発酵に入れる」 | 文脈で一次発酵か二次発酵を判断 |

## 業務の流れに関する補足

- 朝便（morning shift）の製造は早朝に始まり、午前中には焼成・包装まで進むことが多い
- ベンチタイム → 成形 → 二次発酵 → 焼成 の連続性が高く、現場では「焼きに入れる」と言えば二次発酵後の焼成を指す
- 「ホイロ」は設備名（発酵庫）であり、一次発酵にも二次発酵にも使われる。「最終ホイロ」と言えば二次発酵を指す
